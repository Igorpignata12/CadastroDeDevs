Visão Geral do Projeto
Este sistema foi desenvolvido para gerenciar devs e seus projetos. Cada dev pode ser atribuído a um único projeto, enquanto uma projeto pode ser associado a vários devs. As principais funcionalidades incluem:

Cadastro de devs com nome, idade, email e assignee.
Atribuição de um projeto para um dev.
Gerenciamento de projetos e dos devs associados a eles.
